# QR Bharat

A free, private QR code generator for UPI payments, WhatsApp messages, Wi-Fi access, digital visiting cards, menus, email, phone numbers and general links.

All QR codes are generated locally in the browser. No entered data is uploaded or stored.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Live site: https://qrbharat.vercel.app
